# Requirements

- Running/Working SHALL render eight radial dots with a descending opacity trail.
- The dot constellation SHALL rotate continuously using the existing active-state timing.
- Web/Workspace and Windows Shell SHALL use the same point count, ordering,
  opacity values, and clockwise geometry.
- Accessibility labels and spinner/bell/action mutual-exclusion contracts SHALL
  remain unchanged.
