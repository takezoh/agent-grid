# Requirements

## Functional contract

The frontmatter is the canonical EARS projection. FR-GH-INV-001 through FR-GH-INV-006 are cross-flow invariants: in particular, a repository preparation is never an available Session until the sole server reducer commit.

## Outcome partitions

- GitHub account outcomes are unauthenticated, authorizing, authenticated, denied, expired, cancelled, refresh_failed, and host_misconfigured.
- Catalog outcomes are complete-current, refreshing-retained, authentication-required-retained, source-failed-retained, catalog_too_large-retained, and refresh_deadline-retained. An unpublished generation never invalidates selection.
- Preparation outcomes distinguish external retryable failure, unsupported input/environment, cancellation/interruption, and internal_corruption. Internal corruption is fail-fast/quarantined and never fabricates a retry stage.

## Non-goals

GitHub Enterprise, multi-account selection, branch/fork selection, unvalidated extended search metadata, clone sharing, per-session/shared devcontainers, mixed-version compatibility, completed-clone retention policy, and new third-party dependencies are not part of this change.
